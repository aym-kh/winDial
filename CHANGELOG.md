# Changelog

All notable changes to **WinDial** are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Initial Tauri + Angular + Rust project scaffold for the WinDial desktop app.
- Project documentation aligned to the Windows radial-action utility concept and roadmap.
- Release automation scaffold for versioned builds and tagged deployments.
- Transparent, always-on-top radial overlay activated by holding Alt+RightClick, with cursor positioning and hide-on-release behavior.
- Dynamic SVG action wheel with configurable slices, dead-zone-aware pointer selection, active-slice highlighting, and transition feedback.
- Soft tick sound when entering or changing wheel slices.

### Notes
- WinDial is still in its early alpha stage; the roadmap in [.ai/roadmap.md](./.ai/roadmap.md) describes the planned milestones for the first production-ready versions.
